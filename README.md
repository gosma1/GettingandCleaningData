# GettingandCleaningData
Getting and Cleaning Data Project

The R script run_analysis.R combines the training and test data from the data collected from the accelerometers from the Samsung Galaxy S smartphone. A full description is available at the site where the data was obtained: http://archive.ics.uci.edu/ml/datasets/Human+Activity+Recognition+Using+Smartphones

The Script assumes that the data has already been downloaded and it is available in the same directory as the script, but there is additional code (currently commented) that downloads the required data.
